# Contributing

Thank you for contributing to Sprintmark.

1. Open an issue for significant behavior changes.
2. Fork the repository and create a focused branch from `main`.
3. Run `npm ci`, `npm run lint`, `npm run format:check`, and `npm test`.
4. Add tests for behavior changes and avoid committing workspace data or attachments.
5. Open a pull request using the template and resolve review conversations.

Use Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `chore:`). By submitting a contribution, you agree that it is licensed under Apache-2.0.
